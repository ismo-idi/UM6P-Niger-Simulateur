# UM6P-Niger Simulateurs de Concours (écrit, oral)

**Current version:** Computer Science Written Exam — 200 QCM  
**Author:** Assoumane Idi Ismaël  
**Contact:** ismaël.idi@um6p.ma

## Project purpose

**UM6P-Niger Simulateurs de Concours (écrit, oral)** is an independent educational initiative designed to help Nigerien candidates prepare for UM6P admission processes.

The project currently includes interactive preparation modules for oral interviews and written exams, with questions, corrections, revision categories, and exam-style practice.

The goal is to provide candidates with a serious, accessible, and well-structured preparation tool, while encouraging rigorous study, independent reasoning, and responsible use of the materials.

## Current state of the project

The current version includes the following modules:

- **SASE — Oral:** 140 questions.
- **Master Analyse Economique et Politiques Publiques (FGSES) — Oral:** 120 questions.
- **Computer Science (UM6P-CC) — Written Exam:** 200 QCM.

The platform currently contains **460 questions/cards** in total.

## Available modules

### 1. SASE — Oral

This module prepares post-bac candidates for the oral interview of:

**Bachelor of Science in Applied Sciences and Business (SASE)**

It includes questions about motivation, UM6P/SASE, Niger and contribution, mathematics, sciences, economics/business basics, and English.

### 2. Master Analyse Economique et Politiques Publiques (FGSES) — Oral

This module prepares candidates for the oral interview of:

**Master Analyse Economique et Politiques Publiques (FGSES)**

It includes questions about motivation, mathematics, statistics, econometrics, microeconomics, macroeconomics, public policy, economic current affairs, and English.

### 3. Computer Science (UM6P-CC) — Written Exam

This module prepares candidates for the written exam of:

**Cycle Préparatoire Intégré au Cycle Ingénieur en Computer Sciences (BAC+5) (UM6P-CC)**

It includes **200 QCM** covering:

- sequences and limits;
- functions, exponential, logarithm, and continuity;
- derivatives and integrals;
- differential equations;
- complex numbers;
- trigonometry;
- probabilities and counting;
- algebra, arithmetic, and logic;
- geometry;
- general scientific culture.

It also includes revision mode and exam-style practice.

## Recommended use

Candidates should use the platform as a preparation tool, not as a replacement for serious study.

Recommended method:

1. Open the platform in a modern browser.
2. Choose the program and the exam type.
3. Work by category in revision mode.
4. Try to answer before opening the correction.
5. Review mistakes carefully.
6. Use the exam-style sections to simulate real conditions.
7. Revisit weak topics using school notes, textbooks, and official resources.

For written QCM modules, candidates should first solve each question alone before displaying the correction.

For oral modules, candidates should answer aloud before reading the suggested guidelines.
