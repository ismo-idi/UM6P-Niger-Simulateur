# UM6P-Niger Simulateurs de Concours (écrit, oral)

**Version actuelle :** Computer Science — Épreuve écrite — 200 QCM  
**Auteur :** Assoumane Idi Ismaël  
**Contact :** ismael.idi@um6p.ma

## Objectif du projet

**UM6P-Niger Simulateurs de Concours (écrit, oral)** est une initiative pédagogique indépendante destinée à aider les candidats nigériens à préparer les concours et entretiens d’admission à l’UM6P.

Le projet contient actuellement des modules interactifs de préparation aux entretiens oraux et aux épreuves écrites, avec des questions, des corrections, des catégories de révision et des entraînements au format concours.

L’objectif est de fournir aux candidats un outil sérieux, accessible et bien structuré, tout en encourageant le travail rigoureux, le raisonnement autonome et l’utilisation responsable des contenus.

## État actuel du projet

La version actuelle contient les modules suivants :

- **SASE — Oral :** 140 questions.
- **Master Analyse Economique et Politiques Publiques (FGSES) — Oral :** 120 questions.
- **Computer Science (UM6P-CC) — Écrit :** 200 QCM.

La plateforme contient actuellement **460 questions/cartes** au total.

## Modules disponibles

### 1. SASE — Oral

Ce module prépare les candidats post-bac à l’entretien oral de :

**Bachelor of Science in Applied Sciences and Business (SASE)**

Il contient des questions sur la motivation, l’UM6P/SASE, le Niger et la contribution au pays, les mathématiques, les sciences, des bases d’économie/business et l’anglais.

### 2. Master Analyse Economique et Politiques Publiques (FGSES) — Oral

Ce module prépare les candidats à l’entretien oral de :

**Master Analyse Economique et Politiques Publiques (FGSES)**

Il contient des questions sur la motivation, les mathématiques, les statistiques, l’économétrie, la microéconomie, la macroéconomie, les politiques publiques, l’actualité économique et l’anglais.

### 3. Computer Science (UM6P-CC) — Épreuve écrite

Ce module prépare les candidats à l’épreuve écrite de :

**Cycle Préparatoire Intégré au Cycle Ingénieur en Computer Sciences (BAC+5) (UM6P-CC)**

Il contient **200 QCM** couvrant :

- suites et limites ;
- fonctions, exponentielle, logarithme et continuité ;
- dérivation et intégration ;
- équations différentielles ;
- nombres complexes ;
- trigonométrie ;
- probabilités et dénombrement ;
- algèbre, arithmétique et logique ;
- géométrie ;
- culture scientifique générale.

Il inclut également un mode révision et des entraînements de type concours blanc.

## Utilisation recommandée

Les candidats doivent utiliser cette plateforme comme un outil de préparation, et non comme un remplacement du travail personnel sérieux.

Méthode recommandée :

1. Ouvrir la plateforme avec un navigateur moderne.
2. Choisir le programme et le type d’épreuve.
3. Travailler par catégorie en mode révision.
4. Essayer de répondre avant d’afficher la correction.
5. Revoir attentivement les erreurs.
6. Utiliser les parties concours blanc pour simuler les conditions d’examen.
7. Reprendre les notions faibles avec les cours, manuels et ressources officielles.

Pour les modules écrits en QCM, il faut d’abord résoudre chaque question seul avant d’afficher la correction.

Pour les modules oraux, il faut répondre à voix haute avant de lire les pistes proposées.

Ouvrir `index.html` avec un navigateur moderne :

- Google Chrome ;
- Safari ;
- Firefox ;
- Microsoft Edge.

- Android : utiliser de préférence Chrome.
- iPhone : utiliser de préférence Safari.

Éviter d’ouvrir le fichier directement dans ChatGPT, l’aperçu WhatsApp, l’aperçu mail ou certaines visionneuses HTML limitées, car certaines fonctionnalités interactives peuvent ne pas fonctionner correctement.

Pour une meilleure expérience, utiliser le lien GitHub Pages lorsqu’il sera disponible.

## GitHub Pages

Ce projet est pensé pour être compatible avec GitHub Pages.

Structure recommandée du dépôt :

```text
/
├── index.html
├── README.md
├── README_FR.md
├── LICENSE.md
├── LICENCE_FR.md
├── TERMS_OF_USE.md
├── CONDITIONS_UTILISATION.md
└── assets/
```

Pour publier avec GitHub Pages :

1. Créer un dépôt GitHub.
2. Ajouter `index.html` et les fichiers Markdown de documentation.
3. Aller dans **Settings → Pages**.
4. Sélectionner la branche principale et le dossier racine.
5. Sauvegarder et attendre la génération du lien public.
